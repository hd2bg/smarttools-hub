How to use free online PDF tools

PDF tools make it easier to organise, share and prepare documents without installing desktop software.

Merge PDF files

Merging combines multiple PDF documents into one file. Choose the PDFs you want, arrange them in the correct order and use the merge tool to create a combined document.

Split a PDF

Splitting separates selected pages from a larger PDF. This is useful when you only need to share a particular chapter, form or section.

Rotate PDF pages

If a scanned page appears sideways or upside down, a PDF rotation tool can correct its orientation. Check every page before saving the result.

Convert images to PDF

Images such as JPG and PNG files can be placed into a PDF document. Check image order, page size and readability before sharing.

Protect your documents

Only upload documents to services you trust. Avoid processing confidential or sensitive files on unfamiliar websites. SmartTools Hub's PDF tools are designed to process files in your browser, but you should still review the privacy information before using them.

Frequently asked questions

Can I merge multiple PDFs?

Yes. Use a PDF merge tool to combine several documents into one file.

Will splitting a PDF delete the original?

A browser-based tool normally creates a separate output file. Keep your original document as a backup.

Can I use PDF tools on my phone?

Many browser-based PDF tools work on modern phones and tablets, although larger documents may be easier to handle on a computer.
