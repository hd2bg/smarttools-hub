A guide to free online developer tools

Discover simple browser-based utilities for working with data, URLs, text formats and common web development tasks.

Format and validate JSON

JSON is a common format for storing and exchanging structured data. A JSON formatter makes data easier to read, while a validator can help identify syntax errors such as missing commas, brackets or quotation marks.

Encode and decode URLs

URL encoding converts characters into a format that can safely be included in web addresses. URL decoding converts encoded characters back into readable text. Always check the result before using it.

Understand Base64

Base64 represents binary data using text characters. It is useful in some data-transfer situations, but it is not encryption and should never be treated as a way to protect confidential information.

Generate UUIDs

A UUID is a widely used identifier designed to be unique. Developers often use UUIDs to identify records, objects and resources in applications.

Convert CSV and JSON

CSV stores tabular information in rows and columns, while JSON can represent more complex structures. Conversion tools can help move data between these formats, but always check that headings, values and special characters have been preserved.

Work safely with code and data

Never paste passwords, API secrets, private customer records or confidential information into tools you do not trust. Check the output before using it in a live application.

Frequently asked questions

Is JSON the same as JavaScript?

No. JSON is a data format. Although it is based on a subset of JavaScript syntax, JSON has stricter rules.

Does Base64 encrypt information?

No. Base64 is an encoding method, not encryption. Anyone can decode Base64 data.

What is a UUID used for?

A UUID is commonly used as an identifier for records, objects, files and other resources.
